# 05. Add `api_base_override` for testability

- **Status:** Accepted
- **Date:** 2026-11-07
- **Deciders:** @Githab-capibara
- **Related:** `src/providers/avito.rs`, `config.example.toml`, `tests/e2e_mock.rs`

## Context

Боевой Авито отвечает `439 Fingerprint` анонимным клиентам, поэтому весь
пайплайн (fetch → extract → filter → enrich → export → dedup) невозможно
было прогнать end-to-end без валидных cookies и прокси. Юнит-тесты
подменяли только extractors, и дефекты в склейке URL, трактовке ответа
карточки и дедупликации оставались незамеченными.

Реальный прогон против локального мока вскрыл именно такие баги:
`item_base()` складывал override с `/api/1/card/items` к хосту, который уже
содержал `/api/9/items`, и запрос уходил на несуществующий путь; enrichment
при этом молча возвращал `None`, и CSV писался без просмотров.

## Decision

Поле `api_base_override` в `AppConfig` (в оригинале `parser_avito` такого
нет). Оно трактуется как **корень сервиса**:

- каталог получает `+ /api/9/items`;
- карточка — `+ /api/1/card/items`;
- уже-полный путь (содержит `/api/9/items` или `/card/items`) не удваивается.

Значение по умолчанию — `None`, поведение без него побитово совпадает с
оригиналом. `tests/e2e_mock.rs` поднимает мок Авито на `127.0.0.1:0` и
прогоняет настоящий бинарник `avito-rs run --once` дважды, проверяя CSV,
строки `seen` в БД и `new_ads=2 → 0` на втором проходе.

## Consequences

- **Easier:** полный пайплайн проверяется без боевой сети; регрессии в URL,
  парсинге карточки и дедупе ловятся e2e;
- **Harder:** ключ нужно документировать как «не для продакшена», иначе
  оператор случайно направит монитор на свой хост;
- **Given up:** нативный формат ответа карточки Авито остаётся непроверенным
  на живых данных — e2e работает с фикстурой, снятой с одного ответа;
- **Migration:** ключ отсутствует в конфигах оригинала, старые конфиги
  продолжат работать как есть.

## Alternatives considered

- **Option A:** мок на уровне `PageFetcher`-трейта — отклонено: не ловит
  склейку URL и не прогоняет настоящий бинарник;
- **Option B:** VCR-кассеты записанного трафика — отклонено: тянут бинарные
  файлы в репозиторий и ломаются от любого изменения полей;
- **Option C:** feature-gated трейт `Transport` — отклонено: лишний слой ради
  единственного теста.
